# DigiLine web

React/TypeScript client with clinic registration, invitation acceptance, role-based workspaces, server-paged sessions/queues/staff, and realtime refresh/recovery.

See the repository [README](../README.md), [operations](../docs/operations.md), and [verification record](../docs/verification.md).

Run `npm test`, `npm run lint`, and `npm run build` for frontend checks. `npm run test:browser` runs the targeted Playwright/axe suite; its local API and disposable-account requirements are in the verification record. No further load testing is part of this scope.
